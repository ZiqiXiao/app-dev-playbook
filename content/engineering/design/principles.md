# 设计系统框架

适用于有界面的项目（以 React Native 移动端为例）。本文给出设计原则、令牌结构和文档骨架；项目的具体取值（颜色、字号）写在项目自己的 `docs/engineering/design-system.md` 和代码令牌文件中。流程与文案见 [界面与流程规范](ui-flows.md)，边距与间距见 [布局与间距规范](layout-spacing.md)。

## 设计原则

1. **留出呼吸感。** 内容不贴边：按页面类型取边距，相关内容靠近、无关内容拉开，间距取 4pt 网格值。宽度不够时先删减内容，不压缩边距。
2. **一屏一件事。** 每屏只有一个主要操作，用实色主按钮表达；其余操作用次级、文字或图标按钮。按钮、图标和排版能说明的，不再加副标题。
3. **同义同形。** 同一含义用同一颜色、组件和尺寸：危险用 `danger`，选中用 `selected`，链接用 `link`。不为单个页面新增近似颜色、字号或圆角。
4. **动效用于反馈。** 动效只用于按压反馈、输入确认、状态变化和页面交接，时长不超过 500ms，不阻塞操作。系统开启“减弱动态效果”时，位移、缩放和闪烁直接停在终态。
5. **人人可用。** 正文对比度不低于 4.5:1，可点按区域不小于 44pt，适配系统字号放大，读屏能读出每个操作的名称和状态。

## 来源与取值

令牌是代码中的普通对象，不依赖 UI 框架；文档说明用途，代码取值为准。

| 内容 | 位置（示例） | 说明 |
| --- | --- | --- |
| 颜色、字号、圆角、触控尺寸 | `src/ui/tokens.ts`（`palette`、`metrics`） | 代码取值为准 |
| 边距、纵向节奏、限宽 | `src/ui/layout.ts` | 见 [布局与间距](layout-spacing.md) |
| 样式主题 | 由令牌生成的 Tailwind/Uniwind 主题 CSS | 改令牌后重新生成，一致性测试防止遗漏 |
| 品牌页（启动、登录）布局与动效 | 单独的 JSON，可供原生页面读取 | 基础色与 `palette` 共用 |
| 通用组件 | `src/ui/` | 登记在[组件表](#通用组件) |
| 界面原型 | `design/*.pen` / Figma（不进 Git） | 新页面与新样式先在原型确认 |

### 写法约定

- 静态样式写 `className`，取值用主题类名；运行时数值（安全区、测量结果、动画）写 `style`。
- 主题类名与令牌同名（驼峰改连字符）。清空框架默认的颜色、字号和圆角刻度，写错名字时不会生效。
- 文字统一用项目的 `Text` 组件（React Native 原生 `Text` 在 iOS 默认纯黑）；按钮统一用项目的按钮组件；条件类名用配置了主题名的 `cn()`。
- 刻度外的取值暂用任意值保持外观，并登记在[现状差距](#现状差距)。
- 测试断言 `className` 或运行时 `style`，外观由 Storybook 和双端截图核对。

### 新增或修改样式

1. 先用已有令牌。
2. 确需新令牌时，在原型中确认后加入代码，并在设计系统文档登记用途。
3. 在组件预览（Storybook）和双端模拟器上截图核对。

## 令牌结构

### 颜色

按语义命名，不按色相命名。每个令牌写明值、用途和与背景的 WCAG 对比度（注明计算日期）。

| 令牌 | 用途 |
| --- | --- |
| `canvas` | 页面背景 |
| `surface` | 卡片、输入框、底部栏背景 |
| `text` | 正文、标题、主按钮背景 |
| `secondary` | 次要文字、未选中页签 |
| `muted` | 占位、辅助说明（对比度仍需 ≥ 4.5:1） |
| `link` | 文字链接、强调按钮文字 |
| `brand` | 品牌色 |
| `selected` | 选中项和提示块背景 |
| `danger` / `dangerSoft` | 错误、删除、验证失败 |
| `success` / `successSoft` | 已验证、已完成 |
| `warning` / `warningSoft` | 需要注意 |
| `info` / `infoSoft` | 中性提示 |
| `border` | 需要辨认的控件边界（对比度 ≥ 3:1） |
| `divider` | 分隔线、卡片描边，仅作装饰 |
| `disabled` / `disabledText` | 不可用控件 |
| `scrim` | 弹层遮罩 |

- 语义色成对使用：深色写文字和图标，`Soft` 色作底。
- 状态不只靠颜色表达：错误同时给文字提示，选中同时改变字重或图标。
- 层级靠底色区分（`canvas` → `surface` → `scrim` 上的弹层），默认不用投影。

### 字号

使用系统字体，不内置字体文件（品牌字单独定义）。

| 令牌 | 参考值 | 用途 |
| --- | --- | --- |
| `caption` | 12 | 页签名、角标、时间 |
| `body` | 14 | 说明、提示 |
| `field` | 16 | 正文、输入、按钮文字 |
| `item` | 18 | 列表主文字 |
| `title` | 22 | 页面标题 |
| `heading` | 26 | 大标题 |
| `display` | 40 | 大数字 |

- 字重三档：400 正文，600 按钮和强调，700 标题。
- 随时间变化的数字用等宽数字（`tabular-nums`）。
- 系统字号放大到 1.5 倍以上时，横排的标签与值改为上下排列。

### 圆角

| 令牌 | 参考值 | 用途 |
| --- | --- | --- |
| `control` | 12 | 输入框、提示块、强调按钮 |
| `card` | 16 | 卡片、列表分组 |
| `panel` | 26 | 底部面板；主按钮高 52 时取其一半 |
| `pill` | 999 | 胶囊标签、圆形按钮、头像 |

同一层级用同一圆角；嵌套时内层不大于外层。

### 动效

| 用途 | 参考取值 |
| --- | --- |
| 按压反馈 | 按下 80ms 缩到 0.94、透明度 0.65，松开 160ms 恢复 |
| 主按钮按下 | 透明度 0.75，无过渡 |
| 输入确认 | 从 0.6 倍弹出，弹簧阻尼 12、刚度 320 |
| 错误提示 | 左右晃动 ±8pt，共约 460ms |
| 页面交接 | ≤ 420ms |
| 短暂提示停留 | 3000ms |

- 进入用缓出或弹簧，离开用更短的缓入；一次只动一个焦点元素。
- 重复动画只用于需要注意的状态，结束后回到静止。
- 默认遵守系统“减弱动态效果”（如 Reanimated 的 `ReduceMotion.System`）。

### 图标与插画

- 图标统一来源和尺寸（如单色 PNG/SVG 经统一组件着色，默认 24pt）。只有图标的按钮必须提供读屏名称。
- 插画统一风格，同一页面不混用。

## 通用组件

设计系统文档用一张表登记每个通用组件的规格和状态，例如：

| 组件 | 规格 | 状态 |
| --- | --- | --- |
| 主按钮 | 高 52、圆角 26、`text` 底、白字 16/600 | 按下透明度 0.75；不可用为 `disabled` 底 |
| 次按钮 | `surface` 底、1px `divider` 描边 | 同上 |
| 文字按钮 | 透明底、`link` 字、最小高 44 | 同上 |
| 输入框 | 高 52 | 默认/聚焦/错误/有内容各一种边框 |
| 短暂提示 | 左右 `page` 边距，停留 3 秒 | 读屏播报 |

新组件放在 `src/ui/`（跨功能复用）或功能目录（仅本功能使用），并在表中登记。

## 无障碍

- 文字对比度：正文 ≥ 4.5:1；18pt 以上或 14pt 粗体以上 ≥ 3:1；不可用控件豁免。
- 用于辨认控件的边界 ≥ 3:1；纯装饰的分隔线不受限。
- 可点按区域 ≥ 44pt，视觉较小的按钮用 `hitSlop` 补足。
- 适配系统字号放大，文字不截断。
- 每个操作有读屏名称和状态；装饰元素对读屏隐藏。

## 现状差距

设计系统文档末尾保留一节“现状差距”，列出代码与规范不一致之处（刻度外的字号、圆角，对比度不足的组合等），修改相关页面时一并处理。这样规范可以先于代码落地，差距透明可追踪。
