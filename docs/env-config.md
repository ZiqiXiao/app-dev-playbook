# 环境变量与配置

适用于项目配置的字段设计、来源、加载、校验和映射。

## 命名

- 大写字母和下划线，按“服务或项目 + 可选组件 + 参数”命名，使用当前产品名和实际用途；不使用旧产品名、开发阶段或验证关卡编号。
- 一个含义只保留一个名称，各环境、`.env` 和密钥管理服务共用字段名。用配置值和显式目标区分环境，不加 `_DEV`、`_PROD` 后缀。
- 项目自有配置用 `<PROJECT>_*`，如 `<PROJECT>_ENV`、`<PROJECT>_API_BASE_URL`、测试控制 `<PROJECT>_TEST_*`。框架配置沿用框架前缀（如 `DJANGO_*`），平台配置沿用平台前缀（如 `SUPABASE_URL`、`SUPABASE_DB_URL`、`SUPABASE_AUTH_*`）。
- 布尔值用 `*_ENABLED`、`REQUIRE_*` 等明确名称；时间和大小在名称中写单位，如 `_TIMEOUT_SECONDS`、`_MAX_BYTES`。
- 密钥按实际类型命名（如 `SUPABASE_ANON_KEY` 与 `SUPABASE_PUBLISHABLE_KEY` 分开）。消费端显式选择、校验支持的类型并拒绝冲突配置；同一字段不能混用多种密钥。
- 第三方 SDK、工具和容器在接入边界保留原生名称（如 `GOTRUE_*` 只给 Auth 容器），由 runner 或适配层显式映射，不改容器参数名。

## 环境层级

| `<PROJECT>_ENV` | 用途 |
| --- | --- |
| `dev` | 日常开发：本机合成栈或云端开发实例 |
| `staging` | 用 prod 将要部署的同一镜像预演上线，独立实例 |
| `prod` | 生产，配置由运行平台注入，不经过本机加载器 |

## 配置来源

| 来源 | 用途 | 说明 |
| --- | --- | --- |
| 密钥管理服务（如 Infisical）的 Development 环境 | 日常云端开发 | 按用途分目录（如 `/backend`、`/mobile`），后端目录可导入移动端的公开字段；项目绑定（只含项目 ID 和域名）放在已忽略的本机文件 |
| 已忽略的 `.env.*` 文件 | 本机合成栈、隔离测试 | 一份文件完整描述一个栈：栈名、端口、合成凭据 |
| `.env*.example` | 模板 | 唯一进 Git 的 env 文件，只含占位值，不可运行 |

- 选择一个来源后，失败即停止，不回退到其他来源。
- 登录用 CLI 会话或机器身份（Universal Auth）；访问令牌只交给读取配置的 CLI，不注入应用进程。

## 加载入口（env-run 模式）

用一个入口脚本负责“读取 → 投影 → exec”：

```bash
./scripts/env-run [--infisical | --env-file <文件>] <用途> -- <命令...>
./scripts/env-run --env-file .env.dev backend -- python manage.py check
./scripts/env-run --infisical mobile -- ./scripts/mobile.sh run:ios
```

- 每个进程启动时独立读取所选来源；入口读取一次后以 `exec` 替换为目标命令，不保留会话、快照或共享配置进程。
- 按用途投影：客户端只收到公开字段；后端收到其所需的全部字段；工具进程只收到环境白名单中的变量。不从父进程继承业务变量。
- 单字段覆盖用 `--set NAME=VALUE`，只允许该用途可接收的字段。
- 来源必须声明期望的环境层级（如 `dev`），不符即拒绝。
- 远程读取设超时（如 30 秒），失败即停止启动。

### 文件来源校验

- 必须是普通文件，不能是符号链接；仓库内的文件必须被 Git 忽略；`.example` 不可运行。
- 限制最大长度；重复赋值、未知字段、NUL 或无值赋值 → 拒绝。
- 值按字面读取，不展开变量、不执行 shell。

## 秘密边界

- 不通过 `cat`、环境转储、日志或回复展示秘密。错误输出只含变量名和错误类别。
- 客户端只持有可公开的 key；数据库密码和服务端 key 只属于后端。
- 工具生成的文件使用系统默认权限（umask）；原子替换已有文件时保留原权限。秘密边界依靠 Git 忽略和不展示内容维持。
- 远程平台使用 HTTPS；远程 PostgreSQL 省略 `sslmode` 时默认 `require`，显式 `verify-ca`/`verify-full` 原样生效，空或不支持的模式拒绝。

## 变更

- 只增加当前功能需要的变量。
- 更名须同步修改加载器、校验器、runner、消费端白名单、模板、测试、文档和规格；提供显式迁移工具（先预览、再 `--apply`，原子替换并保留注释和权限），不长期保留隐式别名。
- 已运行的进程使用原配置，下次启动生效。
