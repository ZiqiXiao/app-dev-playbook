# 测试与验证

## 按改动选择检查范围

| 改动 | 检查范围 |
| --- | --- |
| 文档 | 相对链接、锚点、命令参数及引用版本 |
| 工程脚本与目录 | 操作入口、跨目录导入、资源定位及相关配置回归 |
| 后端规则与配置 | 相关单元测试、失败路径和配置校验 |
| 数据模型、事务或数据库访问 | 规则测试及真实 PostgreSQL 集成测试 |
| 认证、授权或平台服务适配 | 平台集成测试，覆盖允许与拒绝路径 |
| 移动端业务或界面 | 格式、类型、lint、单元测试，以及双端行为与原型对照 |
| 原生依赖、SDK 或加密配置 | 双端 development/Release 构建及原生运行检查 |
| 运行栈配置 | 本地及 CI 栈的启动、隔离、设施检查和测试资源清理 |

功能验收按本次变更的可观察结果执行，覆盖相关正常和失败路径。

## 证据分层

区分并分别报告以下证据，低层通过不能证明高层：

1. 纯规则 / 单元测试
2. 内存替身或参考实现
3. 真实基础设施（真实 PostgreSQL、隔离的 Auth/Storage）
4. 构建（双端原生构建）
5. 实际运行（模拟器或真机上的端到端流程）

## 测试环境

| 名称 | 目标 | 何时运行 |
| --- | --- | --- |
| 开发环境检查（只读） | 云端开发实例的元数据和健康接口 | 首次接入、连接配置变化、服务升级、连接故障排查 |
| 本机集成测试 | 本机或 CI 的隔离合成栈 | 按改动风险 |
| 云端集成测试 | 已授权的云端开发实例中的临时库 | 迁移、事务、认证、平台配置变化时，显式入口触发 |

- 日常启动和本机测试不自动向云端写入。
- 云端测试保留资源所有权校验和失败清理；`local` 结果不能证明云端行为。
- 测试不得连接生产或使用真实用户资料；日志与截图使用合成资料。

## 目录组织

| 位置 | 内容 |
| --- | --- |
| `backend/tests/`、`mobile/tests/` | 按业务组织的单元和组件测试 |
| `tests/integration/` | 跨服务、迁移、真实平台检查 |
| `tests/tooling/` | 工程脚本、钩子、云操作工具的合成测试 |
| `tests/support/` | 跨套件共享的合成夹具 |
| `tests/e2e/` | 原生检查和双端端到端验证 |
| `*/evidence/*.md` | 长期验收证据 |

## 界面流程回归

见 [界面与流程规范](design/ui-flows.md#流程回归)：验证画面出现的顺序、保留的输入和操作次数，只检查最终页面不能证明中间过程正确。已发生的缺陷保留能重放触发顺序的回归用例。

## 结果记录

记录代码版本、环境、命令或操作、覆盖场景和结果。失败、跳过和未运行的检查分别标明；未确认的事项写“待确认”并说明确认方式。
